1. Introduction & Project Scenario

Short Message Service (SMS) remains one of the most widely used interpersonal communication channels worldwide. However, unsolicited promotional and fraudulent SMS (spam) present severe security and productivity concerns. The objective of this project is to develop an automated Python-based classification system capable of categorizing incoming SMS as either Spam or Genuine message (Ham).

The system evaluates foundational concepts from probability theory and random variables:

  • Computing marginal prior probabilities $P(\text{Spam})$ and $P(\text{Ham})$.
  • Analyzing keyword-conditional probabilities and mathematically verifying Bayes' Theorem.
  • Modeling message classification as a Bernoulli Random Variable ($Y$) and calculating its expectation and variance.
  • Vectorizing text via CountVectorizer and training a Multinomial Naive Bayes classifier with stratified 80/20 train-test splitting.
  • Demonstrating real-time classification and prediction probability estimation.

4. Word-Based Probability Analysis & Bayes' Theorem Verification

To evaluate how specific trigger words alter the probability of a message being spam, five suspicious keywords were selected: free, prize, win, urgent, offer.

1. Direct Empirical Conditional Probability:
$$P(\text{Spam} \mid \text{Word}) = \frac{\text{Spam messages containing Word}}{\text{Total messages containing Word}}$$
2. Analytical Formulation via Bayes' Theorem:
$$P(\text{Spam} \mid \text{Word}) = \frac{P(\text{Word} \mid \text{Spam}) \times P(\text{Spam})}{P(\text{Word})}$$

5. Random Variable Analysis (Bernoulli Distribution)

Let Y denote a discrete random variable indicating the classification outcome of an incoming message:

$$Y = \begin{cases} 1, & \text{if the incoming SMS is Spam} \\ 0, & \text{if the incoming SMS is Ham (Genuine)} \end{cases}$$
Because $Y$ takes values in $\{0, 1\}$, $Y$ follows a Bernoulli distribution with parameter $p = P(\text{Spam}) = 0.1263$:

• Expectation E[Y]:
$$E[Y] = \sum y \cdot P(Y = y) = 0 \cdot (1 - p) + 1 \cdot p = p = \mathbf{0.1263}$$
• Variance Var(Y):
$$\text{Var}(Y) = E[Y^2] - (E[Y])^2 = p - p^2 = p(1 - p) = 0.1263 \times (1 - 0.1263) = \mathbf{0.1104}$$
• Standard Deviation σY:
$$\sigma_Y = \sqrt{\text{Var}(Y)} = \sqrt{0.1104} = \mathbf{0.3322}$$

6. Machine Learning Model Building & Training

To operationalize spam filtering, we implemented a Multinomial Naive Bayes classifier:

  • Dataset Splitting: 80% Training (4135 samples), 20% Testing (1034 samples). Stratified sampling was applied to guarantee that both subsets preserved the identical 12.63% spam proportion.
  • Feature Extraction: CountVectorizer converted message strings into sparse word-count feature vectors with stop-word removal and lowercasing, producing a vocabulary of 7,414 unique features.
  • MultinomialNB Classifier: Suited for discrete word count features: $$P(Y = c \mid \mathbf{x}) \propto P(Y = c) \prod_{j=1}^{D} P(w_j \mid Y = c)^{x_j}$$ trained using Laplace smoothing ($\alpha = 1.0$).
