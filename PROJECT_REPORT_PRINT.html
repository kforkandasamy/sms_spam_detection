1. Introduction & Project Scenario

The objective of this project is to develop an automated Python-based classification system capable of categorizing an incoming SMS message as either Spam or Genuine message (Ham). By computing prior, conditional, and posterior probabilities, mathematically verifying Bayes' Theorem, and defining a Bernoulli random variable model, we establish the statistical foundation of text classification and train an accurate Multinomial Naive Bayes classifier.

6. Machine Learning Model Building & Training

To operationalize spam filtering, we implemented a Multinomial Naive Bayes classifier:

  • Dataset Splitting: 80% Training (4,135 samples), 20% Testing (1,034 samples). Stratified sampling was applied to guarantee that both subsets preserved the identical 12.63% spam proportion.
  • Feature Extraction: CountVectorizer converted message strings into word-count feature vectors with stop-word removal and lowercasing, producing a vocabulary of 7,414 unique features.
  • Multinomial Naive Bayes Architecture:
    Trained with Laplace smoothing (α = 1.0) to prevent zero-probability artifacts on unseen vocabulary.
